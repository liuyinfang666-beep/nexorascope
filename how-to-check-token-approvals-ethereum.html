How to Check Token Approvals on Ethereum

A step-by-step guide to reviewing ERC-20 allowances, understanding spender addresses, and checking permissions before you sign a transaction.

NexoraScope Editorial Team · Published November 28, 2026 · 6–8 min read

In this guide: What an approval means · Why review approvals · Use Etherscan · What to inspect · Before revoking · Common mistakes

When you use a decentralized exchange, lending app, or other Ethereum application, you may be asked to approve a smart contract to spend tokens on your behalf. That permission can remain on-chain after you finish using the app. Reviewing old approvals is a useful part of wallet hygiene—but it is important to understand exactly what a permission does before changing it.

This guide explains how to review token approvals using Etherscan's official Token Approval Checker and what to verify before taking action. It is educational information, not a guarantee that an address or application is safe.

1. What is a token approval?

For a standard ERC-20 token, the approve(spender, amount) function lets a token holder set an allowance for a specific spender address. The spender may then use transferFrom to move tokens from the holder's account up to the remaining allowance, subject to the token contract's implementation. The allowance(owner, spender) function reports the remaining approved amount.

An approval is not the same as a token transfer. It creates a permission. It is also different from simply connecting a wallet to a website: a site connection does not, by itself, establish an ERC-20 allowance.

2. Why should you review old approvals?

Some applications request a very large allowance so users do not need to approve again for each later interaction. This can be convenient, but it may leave a broad permission in place longer than necessary. If the spender is later compromised, malicious, or behaves unexpectedly, an active allowance may increase the amount of tokens exposed.

A large allowance alone does not prove that a spender is malicious, and an approval does not mean funds have already moved. Treat it as a permission to understand—not as an automatic scam verdict.

3. How to check token approvals with Etherscan

Use the official Etherscan site by typing its address yourself or using a bookmark you trust. Avoid approval-checker links sent through unsolicited messages, ads, replies, or direct messages.

  1. Open Etherscan's Token Approval Checker. Navigate from the official Etherscan website or use its Token Approval Checker page.
  2. Enter the public wallet address you want to review. You can review a public address without sharing its private key or recovery phrase. Check that the page is on the Ethereum network.
  3. Review the listed permissions. Etherscan's interface can display token standards, assets, approved spender addresses, allowance information, and related transaction details. Interface labels may change over time.
  4. Inspect each spender independently. Compare the full spender address with the official application documentation and the relevant contract page. Do not rely only on a logo, token name, or address label.
  5. Decide whether the permission is still needed. If you no longer use the application, investigate whether the allowance can be reduced or revoked. Do not revoke blindly if you do not understand the application or the permission.
  6. If you choose to change an approval, review the transaction carefully. Confirm the network, token, spender, wallet account, requested new allowance, and gas fee in your wallet before signing.
  7. Verify the updated state. After the transaction is confirmed, revisit the checker or a trusted on-chain source and confirm the permission changed on the correct network.
Security reminder: A legitimate approval review should never require you to type a seed phrase or private key into a website. Never share those secrets with a person or tool claiming to check or revoke approvals.

4. What should you inspect in an approval list?

  • Network: Confirm you are reviewing Ethereum mainnet, not another EVM-compatible network. Permissions are chain-specific.
  • Token contract: Check the full token contract address, not just its symbol or logo.
  • Spender: Identify the exact contract or address receiving the permission. Cross-check it against independently accessed official documentation.
  • Allowance: Understand whether the permission is limited to a small amount or is very large. Token decimals affect how raw on-chain values are displayed.
  • Transaction history: Review the transaction that granted the permission and any later changes where available.
  • Current need: Consider whether you still use the application and whether it requires the permission for a feature you intend to use.

Do not assume that an address is safe because it has a familiar label, has interacted with many users, or appears in a search result. Verify the address through more than one trustworthy source.

5. What to know before revoking an approval

Revoking or reducing an approval is an on-chain state change. It generally requires a transaction and a network gas fee. The transaction must be confirmed before the permission is updated. Make sure you understand the new allowance value and that the transaction is being sent on the intended network.

Revocation affects the permission going forward. It cannot reverse token transfers that have already completed, recover stolen assets, or remove a different approval granted to another spender or on another chain. Disconnecting a wallet from a website is also not the same as revoking an on-chain allowance.

For more detail, read our guide: How to Revoke Ethereum Token Approvals Safely.

6. Common approval-checking mistakes

  • Using a look-alike website instead of the official block explorer.
  • Confusing wallet connection with an on-chain token approval.
  • Checking the wrong blockchain network.
  • Assuming every large allowance is malicious—or assuming a familiar spender is automatically safe.
  • Signing a transaction without checking the token, spender, network, allowance value, and gas fee.
  • Believing revocation can recover tokens that have already been transferred.
  • Entering a recovery phrase or private key into an approval checker.

Frequently asked questions

What is an ERC-20 token approval?

An ERC-20 approval sets an allowance that lets a specified spender address transfer up to an approved amount of tokens on behalf of the token holder, subject to the token contract's implementation.

Does connecting my wallet mean I have approved token spending?

Not necessarily. Connecting a wallet to a website and granting an on-chain token allowance are separate actions. Always inspect the transaction or signature request.

Is an unlimited token approval always malicious?

No. Some legitimate applications request broad allowances for convenience, but a large allowance can increase exposure if the spender is compromised or malicious.

Can revoking an approval recover tokens already transferred?

No. A confirmed revocation changes a permission going forward. It does not reverse completed transfers or recover assets.

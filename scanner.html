Important limitations

This beta checks third-party security intelligence and publicly available contract metadata. It is not a formal audit, does not guarantee safety, and may not detect every exploit or malicious behavior. Missing or unavailable data is not a clean bill of health. No wallet connection, transaction signing, approval revocation or asset recovery is performed.

What this scanner checks

Wallet address

Known malicious-address signals and supported token/NFT approval risk data where the provider supports the selected chain.

Token contract

Token risk indicators such as source verification, proxy status, minting controls, blacklist controls, pausing, taxes and honeypot signals where available.

Contract metadata

Verified-source metadata from a configured Etherscan-compatible API key. This is metadata retrieval, not a complete code audit.
